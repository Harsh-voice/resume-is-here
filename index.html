The 30-day plan

The short version. Broken into phases just below, if you want it that way.

Days 1–10, learn the funnel by using it. I sign up for the API the way a first-time developer would, time every step from landing page to first successful call, and write down each place I hesitate — because those are the same places signups drop off. Alongside that I audit what already exists: which docs pages and blog posts pull organic traffic, which keywords Sarvam ranks for against competitors, and how Sarvam’s models get described when you ask ChatGPT, Perplexity and Gemini about Indian-language speech and translation — increasingly that answer is the top of the funnel. Days 11–20, ship the cheapest fixes. I turn the audit into a ranked list where every item has an owner, an effort estimate and a number it should move, then publish the two or three highest-leverage pieces myself — a comparison page that captures existing search demand, a developer-facing tutorial that ends in a working call, and the metadata and schema changes that make both easier for search engines and LLMs to quote. Days 21–30, prove it with numbers. I set up one dashboard the team actually opens — signups, activation rate, time-to-first-call, organic sessions and assisted conversions in one view — run at least two honest experiments against it, and close the month with a short written readout: what moved, what didn’t, what I’d kill, and the three bets worth a bigger budget in month two. The goal for thirty days isn’t a vanity spike. It’s leaving behind a measurement setup and a backlog the team keeps using after the internship ends.

What I’d measure

Four numbers I’d want on one screen before I argue for spending anything.

  1. 01

    Time to first call

    Minutes from landing page to a developer’s first successful API response. The best proxy there is for activation friction.

  2. 02

    Signup → activation

    What share of signups ever make that first call, split by source. Tells you which channels bring builders and which bring tourists.

  3. 03

    Organic & assisted

    Sessions and assisted conversions from search and docs, tracked per page so content decisions stop being guesswork.

  4. 04

    Share of AI answers

    How often Sarvam is named when an LLM is asked about Indic speech, translation or sovereign AI. Increasingly the real top of funnel.
