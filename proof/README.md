# Receipts

The screenshots live on `proof.html`, not the main page. `index.html` carries a
single pointer card to it.

To add or swap one, edit `proof-template.html` in the clone scratchpad and
rebuild — `build.py` writes `index.html`, `proof.html`, `styles.css` and
`fonts/`.

## Before you export

- Blur or crop campaign names and the ad account name.
- Check the top-left account switcher and any avatars.
- Dismiss Instagram's notification pill — it sits over the Followers row in
  two of these.
- Leave the **totals row** alone — it is the thing being shown.
- Set the date range deliberately. "Maximum" defaults back to the account's
  first ever campaign, which may predate the role you are claiming.
